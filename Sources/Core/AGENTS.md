# Sources/Core —— 写入安全红线

本目录只讲一件事：**写别人的配置文件**。其余见[根规范](../../AGENTS.md)。

15 个文件里，跟写盘有关的就这几个，改它们之前先读完这一页：

| 文件 | 干什么 |
|---|---|
| `JSONValue.swift` / `TOML.swift` | 保序解析，顺手记下每个值的**字节区间** |
| `JSONPatch.swift` / `ConfigPatch.swift` | 决定这次改动是"按字节替换"还是"整份重写" |
| `JSONFile.swift` / `FileSupport.swift` | 唯一写盘入口：指纹、备份、原子替换 |
| `PathResolver.swift` | 所有路径解析 + `scopeGuard` 白名单 |

## 九条红线

1. **解析失败的文件一律不许写**。禁用编辑入口、给原文视图和外部编辑器，
   绝不"尽力而为"地覆盖 —— 用户的东西比我们的功能重要。
2. **落盘前比对 sha256**。不一致就中止并说"文件已被外部（很可能是 agent）改动"。
   agent 的配置文件正在被它自己改写是常态，不是异常。
3. **能按字节替换就按字节替换**。只有一个或多个叶子值变了 → 把新字面量拼进原始
   字节，别动没碰过的行。注释、内联表、用户自己排的格式都要活下来。
4. **结构改动按格式分级**：JSON 整份重写（无注释，无损）；TOML 只重排受影响的表，
   顶层增删才整份重写**并在确认页明说注释会丢**。
5. **写前备份**，同目录 `<file>.bak-agentkit-YYYYMMDD-HHMMSS`，每个文件留 10 份。
6. **保留权限**。`models.json` / `auth.json` / `config.toml` 是 0600，写回后仍是 0600。
7. **原子替换**：同目录临时文件 → `fsync` → `rename`。不要直接覆盖原文件。
8. **路径护栏**：解析后的目标必须落在描述文件声明的 `scopeGuard` 内。
9. **动到内存里的东西要能过构造函数**。`@State` 那份数据最终还是要走这条写盘路径，
   在 View 里"先改了再说"等于绕过全部九条。

## 三条容易踩的

- **`URL(fileURLWithPath:)` 不会拒绝相对路径** —— 它按**进程工作目录**解析，
  而 GUI 程序的工作目录是 `/`。所以 `"AGENTS.MD"` 会变成 `"/AGENTS.MD"`。
  路径只在 `PathResolver` 里产生，别在别处拼。
- **`readDataToEndOfFile()` 会抛 ObjC 异常**，Swift 接不住，直接 abort。
  读管道用 `AgentProcess.drain`（`read(upToCount:)`，会抛错而不是抛异常）。
  同理：**先 `process.run()` 成功，再启动读取器** —— 反过来的话，启动失败时
  关读端会踩到正在阻塞读的句柄。
- **别用字符串比路径判"同一个文件"**。macOS 卷不区分大小写，用
  `PathResolver.isSameFile`（比 device + inode）。

## 风格

- 注释写**为什么**，不写"这里做了什么"。尤其是"为什么不用更直观的写法" ——
  这一层几乎每条绕路的代码背后都有一个踩过的坑，坑不写下来就会被改回去。
- 注释用中文，和这个仓库其它地方一致。
